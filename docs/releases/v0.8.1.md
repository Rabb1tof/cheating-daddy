# Cheating Daddy 0.8.1

This release provides installers for Windows x64 and macOS 15+ on Apple Silicon. It includes persistent language selection, provider model discovery and manual model entry, Groq support, and paced fallback across models.

Download the `.exe` for Windows or the `.dmg` for macOS. `SHA256SUMS.txt` contains checksums for both installers.

The Windows installer is unsigned. The macOS app is unsigned and not notarized; after the first launch attempt, macOS may require **System Settings → Privacy & Security → Open Anyway** ([Apple instructions](https://support.apple.com/en-au/102445)). Grant microphone and screen/system-audio capture permissions when prompted for audio features.

Both installers passed GitHub Actions packaging checks. The macOS audio helper was compiled from attributed MIT source and checked inside the app bundle. Live provider calls and audio capture on a physical Mac were not exercised for this release.
