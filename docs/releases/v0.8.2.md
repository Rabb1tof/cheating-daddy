# Cheating Daddy 0.8.2

This update fixes model selection and session startup in the Windows x64 and macOS 15+ Apple Silicon installers.

- Gemini Live, Groq speech and response, and screenshot models now use a regular dropdown with a separate field for manually entered model IDs. Each field shows its own available model count.
- The Groq API key is visible in the Transcription section when Groq speech is selected.
- Gemini Live startup errors appear on the setup screen, and a connection that closes before setup finishes no longer leaves Start Session waiting indefinitely.
- Gemini Live suggestions include native audio models returned by the current account's model catalog.
- The Provider limits section shows Groq requests/day and tokens/minute values observed in actual responses, with the model and observation time. Gemini's remaining project quota is not exposed through an API key; the section links to the AI Studio dashboards. No extra inference requests are made to collect limits.

Download the `.exe` for Windows or the `.dmg` for macOS. `SHA256SUMS.txt` contains checksums for both installers.

The Windows installer is unsigned. The macOS app has an ad hoc signature but no Developer ID signature or notarization; after the first launch attempt, macOS may require **System Settings → Privacy & Security → Open Anyway** ([Apple instructions](https://support.apple.com/en-au/102445)). Grant microphone and screen/system-audio capture permissions when prompted. These permissions may be requested again after an update.
