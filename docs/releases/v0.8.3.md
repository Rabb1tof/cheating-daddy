# Cheating Daddy 0.8.3

- Fixed Home scrolling when several configuration sections are expanded. The top of the form remains reachable.
- Replaced the dense Groq limit text with cards for requests per day and tokens per minute, including the response time and reset time.
- Added Gemini token usage from Live messages and completed screenshot/text requests. Live shows the latest reported snapshot; HTTP request totals cover this app session only.
- Added optional Gemini free-tier project quota lookup for selected models through Google Cloud Application Default Credentials. Enter a project ID and refresh manually. Cloud Monitoring usage samples are shown when the project supports them; Google may require billing to read them. This does not make an inference request, and samples are not an exact remaining balance. Gemini and Groq sessions work without this optional sign-in.
- Documented Windows per-user installation and the macOS DMG drag-to-Applications step.

## Install

- Windows: run `Cheating-Daddy-0.8.3-Setup-x64.exe`. The entry is named **Cheating Daddy** under the current user's Installed apps. The installer is unsigned.
- Apple Silicon, macOS 15+: open `Cheating-Daddy-0.8.3-arm64.dmg` and drag **Cheating Daddy.app** to **Applications**. The app is ad hoc signed, not notarized; macOS may require **Open Anyway** on first launch.

The Gemini project quota panel needs a Google Cloud project ID and `gcloud auth application-default login`, with read access to Cloud Quotas. Cloud Monitoring samples also need its API and may require a billing-enabled project. This is optional and separate from the Gemini API key.
