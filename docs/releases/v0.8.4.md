# Cheating Daddy 0.8.4

- Added a **Detailed answers** setting for Gemini and Groq. It uses the resume, job description, and instructions in AI Context to give fuller, grounded replies. The setting takes effect when a new session starts; concise answers remain the default.
- Text, voice, and screenshot answers appear as they stream. A new request does not overwrite an earlier answer: each stream completes in its own response entry. Gemini Live keeps generating when new speech arrives. The answer view follows new text while you are near the bottom and keeps your position when you scroll up.
- Two independent response checkboxes control whether a new request interrupts an answer, and whether a bounded set of completed answers from the current session is included in later requests. Both take effect with the next session. The interruption option defaults off; memory defaults on. Gemini Live retains its own active connection context, and the cloud service cannot be cancelled from this app.
- Added an explicit response provider choice. Existing Gemini transcription with Groq answers remains selected after upgrade; new Groq keys no longer silently switch Gemini Live answers.
- Detailed Groq text answers allow up to 1,024 output tokens, versus 512 in concise mode. This is a conservative per-answer cap to limit free-tier usage; longer answers consume more tokens and can reach provider limits sooner.
- Screenshot prompts preserve requests for full code or exact multiple-choice answers. Long Groq screenshot context is shortened to fit the free-tier request budget.
- Model-supplied Markdown is rendered without executing embedded HTML, loading remote images, or opening scriptable links.

## Install

- Windows: run `Cheating-Daddy-0.8.4-Setup-x64.exe`. The per-user installer is unsigned; the app appears as **Cheating Daddy** in Installed apps.
- Apple Silicon, macOS 15+: open `Cheating-Daddy-0.8.4-arm64.dmg` and drag **Cheating Daddy.app** to **Applications**. The app is ad hoc signed, not notarized; macOS may require **Open Anyway** on first launch.

The optional Google Cloud OAuth sign-in for Gemini project quota lookup is separate from the Gemini API key and is not required for inference.
