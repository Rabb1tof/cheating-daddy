# Cheating Daddy 0.8.5

- Fixed an Apple Silicon macOS startup crash where dyld rejected Electron Framework with `different Team IDs` before the app could open. The ad hoc signing configuration now explicitly disables hardened runtime, whose library validation requires a Team ID that ad hoc signatures do not provide.
- The macOS build now verifies the app copied from the finished DMG, checks the app and nested code signatures, and launches its executable for 10 seconds. Early startup termination fails the release build.

## Install

- Apple Silicon, macOS 15+: download `Cheating-Daddy-0.8.5-arm64.dmg`, open it, and drag **Cheating Daddy.app** into **Applications**, replacing the previous copy. Launch the app from **Applications**. The app is ad hoc signed, not notarized; macOS may require **System Settings → Privacy & Security → Open Anyway** on first launch ([Apple instructions](https://support.apple.com/en-au/102445)).
- Windows x64: run `Cheating-Daddy-0.8.5-Setup-x64.exe`. The per-user installer is unsigned.

`SHA256SUMS.txt` contains checksums for both installers. The macOS CI launch check does not cover microphone/system-audio capture or Gatekeeper approval on a physical Mac.
